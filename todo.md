Project: Veterinary Practice Management System (VPMS)

Technology:
- C++
- Qt Creator (Qt Widgets for GUI)

Constraints:
- No database systems allowed
- All data must be stored using C++ file streams

Team:
- 4 developers

Modules:
1. Core Architecture & Integration (ClinicService, Repository, Exceptions)
2. Animals & Owners
3. Visits & Services
4. Inventory & Hospitalization

Requirements:
- Must demonstrate OOP concepts:
  - Inheritance
  - Polymorphism
  - Operator Overloading
  - Exception Handling
  - File Handling
- GUI required (Qt Widgets)

Goal:
Design a clean, modular, and scalable system suitable for a university-level OOP project.
